# ExtendSpace beta: quick start

Once [Windows](install-windows.md) and [Android](install-android.md) are set up:

1. Connect the device to the PC with a USB data cable. Unlock it.
2. Device: open **ExtendSpace** → **Wait for PC**.
3. PC: open **ExtendSpace** → Home: the device shows **Ready** → pick the **display** → **Connect**.
4. Use it. Tap the picture on the device to see **End session**.
5. End: **Disconnect** on the PC, or **Back** on the device.

Problems: [troubleshooting](troubleshooting.md). Limits: [known issues](known-issues.md).
Report: [feedback and bug reports](reporting.md). What to try: [beta test checklist](test-checklist.md).
